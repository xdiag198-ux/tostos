# Tosto на iPhone (веб-приложение на экране «Домой»)

Настоящее iOS-приложение требует аккаунт Apple Developer (99 долларов в год). Бесплатный путь: открыть Tosto в Safari и добавить на главный экран. Выглядит и открывается как приложение, без адресной строки.

1. GitHub → Actions → последний зелёный запуск → внизу Artifacts → скачай `tosto-web`, распакуй zip. Получится папка с файлами (`index.html`, `assets`...).
2. Открой app.netlify.com/drop (нужен бесплатный аккаунт, иначе сайт удалится через час), перетащи папку целиком. Netlify выдаст адрес вида `https://название.netlify.app`.
3. Supabase → Authentication → URL Configuration: добавь в Redirect URLs `https://название.netlify.app/**` и укажи этот адрес как Site URL (Site URL можно оставить прежним, если нужен локальный запуск: тогда достаточно Redirect URLs).
4. На iPhone открой адрес в Safari (именно Safari, не Chrome) → кнопка «Поделиться» → «На экран «Домой»» → Добавить.
5. Запускай Tosto с иконки.

Ограничения версии для iPhone:
- Нет пуш-уведомлений (они сделаны только для Android).
- Звуки включаются после первого нажатия на экран.
- Вход через Google в режиме «с экрана Домой» на iOS иногда ведёт себя капризно. Если не войдёшь, открой адрес в обычном Safari, войди там, потом открывай с иконки.
- Обновления: после новой сборки загрузи новую папку в Netlify на ту же страницу сайта (Deploys → Drag and drop), адрес не изменится.
